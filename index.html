NeoIQ service onboarding — Facets E2E

Public preview artifact (open this file in any browser). Covers GitHub app repo, Bitbucket ciq-facets, ECR, Facets registration, ingress, and runtime config. Examples: B = pim-spapi-orchestrator (Databricks); A = neoiq-ai-visibility-service (Postgres).

Two repos: Application code lives on GitHub (commerceiq/<service>). Kubernetes/Facets definitions live on Bitbucket (commerceiq/ciq-facets, project ciq-apps). facetsctl push from CI registers an image; a Raptor release usually rolls pods.
